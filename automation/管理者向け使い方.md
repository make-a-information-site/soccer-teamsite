# 船橋パレタ サイト更新のしかた(チーム管理者向け)

LINEの公式アカウントに送るだけです。数十秒〜数分でサイトに反映されます。

## かんたん入力(おすすめ)

1. `メニュー` と送ります(何か適当な文字を送っても出ます)。
2. 画面下に出るボタンから「練習」「練習試合」「公式戦」「相手を募集」を選びます。
3. カレンダーと時計が出るので、日付と開始時刻を選びます。
4. 「2時間」など、終わりの時刻をボタンで選びます。
5. 会場をボタンで選びます。初めての会場は、会場名をそのまま送ります。

スマホのLINEで使ってください(パソコン版ではカレンダーが出ないことがあります)。

## 文字で送る方法

| やりたいこと | 送る文 |
|---|---|
| 予定をのせる | `予定 12/13 9:00-11:00 ○○グラウンド` |
| 試合の予定をのせる | `予定 12/13 9:00-11:00 ○○グラウンド 公式戦` |
| 練習試合の相手を募集する | `募集 12/20 13:00-15:00 ○○グラウンド` |
| 今のっている内容を見る | `一覧` |
| まちがえたので消す | `削除 Y3`(記号は「一覧」に出ます) |
| 使い方を忘れた | `ヘルプ` |

- 日付・時間・会場のあいだは **スペース** で区切ってください。会場名の中にはスペースを入れないでください。
- 「12月13日 9時〜11時」という書き方でも通じます。
- 直したいときは、消してからもう一度送ってください。

## 練習試合の申し込みが来たら

LINEに「申し込みが来ました」と届きます。**受ける** か **見送る** を押すだけです。
受けると、予定表への掲載と相手チームへのメール連絡まで自動で行われます。

## お願い

- 選手の名前・電話番号などの個人情報は送らないでください(会場名とメモはそのままサイトに出ます)。
